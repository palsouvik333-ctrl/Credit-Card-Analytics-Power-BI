# Credit Card Analytics Dashboard | Power BI

## Project Overview
This project focuses on credit card data analysis using Microsoft Power BI. The dashboard is designed to visualize credit card-related data and help understand financial performance, customer trends, and transaction patterns.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Project Objectives
- Analyze credit card data.
- Explore customer and transaction-related trends.
- Monitor key performance indicators (KPIs).
- Visualize data to support better analytical understanding.

## Dashboard Features
- KPI visualization
- Customer data analysis
- Transaction analysis
- Interactive reports and charts

## Project File
- `credit_card_report.pbit` – Power BI report file.

## How to View
1. Download the `.pbit` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the report and visualizations.
